Architecture review · Selective Service rehearsal · 2 / 8

Choice 1: the stack

Chosen

React 18, Vite and Tailwind. Node, Express and TypeScript. One deployable API.

Rejected

LangChain and LangSmith for the assistant. Claude through the official SDK instead, with native citations.

Price paid

No frontend unit tests. The pages are checked end to end by scripts.

Architecture review · Selective Service rehearsal · 3 / 8

Choice 2: one PostgreSQL database, no cache

Chosen

PostgreSQL only. 28 migrations apply by themselves on start, in order, forward only.

Rejected

Redis and Elasticsearch, which the day-one plan named. A cache for data status: every page reads the database directly.

Price paid

No down migrations. A rollback of code does not undo a migration.

Architecture review · Selective Service rehearsal · 4 / 8

Choice 3: sign-in, two-step codes and policy checks

Chosen

Hashed passwords and a one-hour token. A 6-digit authenticator code, used once, 5 tries.

Open Policy Agent decides every request first.

Rejected

Roles from an email list. Roles are now given in the app, with a reason, and a role is never cached between requests.

Accepted risk

Tokens in browser storage. Production should use HttpOnly cookies.

Architecture review · Selective Service rehearsal · 5 / 8

Choice 4: an audit log the database protects

Chosen

The database refuses update, delete and truncate on the log. Kept 7 years. Secrets removed before writing.

Rejected

A constraint that cannot fail. The first "immutable" table used CHECK (true).

Still open

A database superuser could disable the triggers. Production needs an append-only copy, which was never built.

Choice 5: deployment, hosted and then local

Chosen

Render for the demo, from 2026-08-31 to its deletion on 2026-11-06. Then a local run from a clean checkout.

Rejected

Local Docker, because the machine blocked it. And applying AWS GovCloud, which is closed.

Written, not applied

GovCloud infrastructure as code is formatted and validated. About $5,850 a month, an estimate.

Architecture review · Selective Service rehearsal · 7 / 8

What would change my mind

Real applicants

Then cookies for sessions, an append-only audit copy, and an independent test.

Real load

Past 128 connections, measure again on a production-like stack.

A real cloud

Then apply the infrastructure code after a plan and an approval.

A real model risk

If answers drift, the quality alerts say so, and the model can be turned off.

The choice I am least sure of

Tokens in browser storage

Right for synthetic data. Wrong the day a real applicant signs in.

What protects it

Sign-out ends the session on the server. Throttling and one-time recovery codes. Our own testing: attack suite 52 of 52.
